# Ansible Server Build Automation

## Overview

Infrastructure automation project using Ansible.

This playbook automates server provisioning and configuration tasks.

## Automated Tasks

- Package installation
- User creation
- Firewall configuration
- Nginx deployment
- Service validation

## Technologies

- Ansible
- YAML
- Linux

## Example Execution

```bash
ansible-playbook site.yml
```

## Benefits

- Consistency
- Repeatability
- Reduced manual effort
- Faster server deployment
